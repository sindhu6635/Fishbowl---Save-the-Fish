# 🐠 Fishbowl – Save the Fish

A creative and interactive fishbowl animation where a little fish needs your help! 🌊💗

**Fishbowl – Save the Fish** is a visually appealing web animation featuring a transparent glass fishbowl, a cute little fish, underwater plants, and a water refill mechanism. The project combines creative design, smooth visual effects, and interactive elements to create an engaging aquatic experience.

## ✨ Features

- 🐠 **Cute Little Fish:** A small animated fish inside a beautiful fishbowl.
- 🫧 **Transparent Fishbowl:** A glass-effect bowl with realistic transparency and highlights.
- 💧 **Water Refill Mechanism:** An interactive refill button to add water to the fishbowl.
- 🌿 **Underwater Plants:** Decorative aquatic plants that create a natural underwater environment.
- 🎨 **Beautiful Pink Background:** A soft pink theme with attractive visual effects.
- 🌈 **Gradient Effects:** Smooth gradients, shadows, and glass-like styling.
- 🖱️ **Interactive Elements:** Click the refill button to interact with the fishbowl.

## 🚀 Getting Started

Follow these simple steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/sindhu6635/fishbowl-save-the-fish.git
```

**2. Navigate to the project folder**

```bash
cd fishbowl-save-the-fish
```

**3. Run the project**

Open the `index.html` file in your web browser.
